job or old-to-new checkpoint conversion was performed. At most four build/test
workers ran concurrently; simulations were sequential.

## Evidence

- `entry.json`: actual root, branch, initial HEAD/origin-tracking, incoming dirty
  work, source hashes, five preserved core/checker copies and 33 earlier controls.
  `entry.patch` and `entry-source.tar.gz` are retained local recovery artifacts.
- `final-provenance.json`: source and actual binary hashes, commands for all 12
  native runs, and verification of all 39 protected files. The extra preserved
  BP3 fixture library is identified in `additional-bp3-control.json`.
- `runs/*/{command.json,input.prm}`: compact native input and execution records.
  Full outputs, raw logs and local lifecycle checkpoints remain under the
  `build-particle-free/transported-objective/stage-c` paths in those records.
  Serial fixture inputs are also copied here. No large output/checkpoint copy.
- `build*.log`, `checker-build*.log`, `serial-*.log`, `bp3-plugin-build.log`:
  successful builds and the initial missing-test-access-include failure, fixed
  without numerical changes. `independent-compile.json/log` records standalone
  no-unity/no-PCH compilation of extracted code and affected BP3 checkers.
- `unit-tests.log`, `unit-summary.txt`: full existing unit suite, 183170 assertions
  in 152 cases. This is not the deferred full ASPECT integration testsuite.
- `equivalence.json/log`: all matching accepted bulk/surface values,
  reconstructed physical tensor/work traction, publication counts, iterations,
  direct/separated physical pairs and existing profile/state/energy reducers.
  `default-comparison.json`: retained default control and current default case.
- `serial-inputs.json`, `consolidation-{limiter,stabilization}.{json,log}` and
  `serial-comparison.json`: unchanged native assertions and historical CSV
  differences of migrated scratch experiments. These are not all bitwise equal.
- `layered-operator.csv`, `layered-operator-comparison.json`: both directions of
  standalone layered transport, byte-identical to retained `layered-native-r3`.

## Reproduction

Use a fresh label/output directory to preserve completed evidence. Existing
runners refuse reuse; the equivalence reducer also refuses to overwrite its
completed JSON. Inputs and command records specify flags, runtime libraries,
rank counts and actual binary hashes, rather than relying on embedded revision.
Build commands for the current source, run sequentially:

```sh
cmake --build build-particle-free/native --parallel 4
cmake --build build-particle-free/transported-objective/stage-c/checks --parallel 4
cmake --build build-particle-free/stress-history-consolidation/checks --parallel 4 --target limiter_checks stabilization_checks transport_checks native_method_checks pf5_checks pf6a_checks pf6_transfer_checks p3_native_checks pf6a_spatial_checks
ctest --test-dir build-particle-free/native -R '^unit_tests$' --output-on-failure
```

The serial checker directory was configured from
`benchmarks/reconstructed_fault/particle_free` with `Aspect_DIR` pointing to
this worktree's native build. Preserve current binaries before rebuilding;
compile matching checker DSOs after internal history/interface changes.
`LD_LIBRARY_PATH=/opt/openmpi/5.0.6/lib` is required for the local MPI runtime.
Native commands are generated by `transported_objective/run_material_native.py`
and `run_stage_c_native.py`; exact completed invocations and environments are
in `runs/*/command.json`. The operator fixture uses `--steps 0 --refinement 3
--transport-check --layered-check --ranks 2 --seconds 120`; it is no BP3 event.
The comparison command was:

```sh
python3 benchmarks/reconstructed_fault/particle_free/transported_objective/check_stress_history_consolidation.py
```

It reads retained pre/post exports and compares common accepted clocks with the
predeclared 5e-13 bulk / 5e-12 surface screens. Checkpoint continuation explicitly
uses a fresh entry local test checkpoint in the same law, changing two ranks
to four. Default/lifecycle and experimental operators are distinct controls.
Prior direct-stress, frozen-endpoint and cleanup evidence remains separate;
none of the historical data losses is repaired or hidden by this directory.
