# PF4 transport-method comparison evidence

See [measured report](../../../../../doc/reconstructed_fault/particle_free/PF4_METHOD_COMPARISON_REPORT.md)
and [status](../../../../../doc/reconstructed_fault/particle_free/STATUS.md).
This is serial, fixed-grid prescribed transport only. Unlimited DG remains the
resolved smooth baseline. Scaling bounds stay benchmark-only; both WENO paths
remain experimental. No WENO threshold tuning/timestep sweeps, production
history replacement, coupled evolution, BP3 or PF5 was performed.

- `assessment.json`: independent exact split-polynomial L2 projection,
  representation/evolution/initialization errors, transported-initial-field
  errors, extrema, all three front widths, integral/norm errors, time differences,
  actual DoFs/costs and native-history weak loads. The standalone Legendre result
  is **0.149862170276557**, verifying the sharp 32×64 prediction.
- `reference.tar.xz`: fourteen run records, expanded inputs/logs and field CSVs;
  native weak quadrature/association weights and DG load contractions; exact
  benchmark source snapshots; two failed initial-startup records/logs.
  Eight successful scalar and two native-history controls are new. Four DG/
  scaling controls are retained unchanged-source evidence. Their original logs
  include historical WENO measurements, but no WENO fields are re-evaluated here.
- `provenance.json`: exact identities, new-run/build/analysis commands, source
  hashes, run selection and archive hash. All fourteen records have the same
  production executable; all eight scalar controls share one final plugin.
- `verification.json`: reference gates, native tests, style, preservation,
  nonintrusiveness and replay results.
- `comparison.png`: sharp/finite analytic profiles, DG best projection and the
  measured methods at t=.2. Uses DG dt/4 and scalar dt/2; the report's primary
  tables use identical base dt and separately state temporal uncertainty.

The field archive stores scalar CG polynomials in a redundant cellwise Q2
format for independent evaluation. DoFs in the report/metadata are actual native
continuous DoFs. Mass/projector code is independent Python/NumPy/SciPy. Sharp and
native-history polynomial products use exact split Gauss3 integration; the
finite profile uses Gauss16 checked against Gauss24. The L1 field is explicitly
labeled a quadrature estimate; reported L2, signed tensor integrals and Q have
the documented exact/converged integration. Widths/extrema use the y=.5 trace,
count crossings through DG face jumps, and retain measured transverse variation.

Native independent history is generated by `make_dg_history_trial` from native
Q2 FE strain. The final source includes an asymmetric y term so both shear and
normal weak loads are nonzero. Earlier symmetric-source diagnostics and all raw
pinned binaries remain under `build-particle-free/runs/pf4-methods-*`; they are
not mixed into the final comparison. New-run directories refuse overwrite.
Full run budgets are 180 seconds, one rank/thread, at most two concurrent.
All successful final runs finish in at most 126 seconds. This is not a dedicated
performance-node benchmark: native scalar solvers reassemble, while this DG
fixed-coefficient experiment preassembles its matrix.

## Replay without ASPECT

Requires Python, NumPy and SciPy. From the repository root:

```sh
mkdir -p /tmp/pf4-methods-replay
 tar -xJf benchmarks/reconstructed_fault/particle_free/evidence/pf4_methods/reference.tar.xz -C /tmp/pf4-methods-replay
python3 benchmarks/reconstructed_fault/particle_free/evidence/pf4_methods/replay.py /tmp/pf4-methods-replay --output /tmp/pf4-methods-replay/assessment.json
cmp benchmarks/reconstructed_fault/particle_free/evidence/pf4_methods/assessment.json /tmp/pf4-methods-replay/assessment.json
```

Optional figure reconstruction (also needs Matplotlib):

```sh
MPLCONFIGDIR=/tmp/pf4-methods-mpl OPENBLAS_NUM_THREADS=1 python3 benchmarks/reconstructed_fault/particle_free/plot_methods.py --dg /tmp/pf4-methods-replay/pf4-stabilization-final-32-4 --ev /tmp/pf4-methods-replay/pf4-methods-final-ev-32-2 --supg /tmp/pf4-methods-replay/pf4-methods-final-supg-32-2 --output /tmp/pf4-methods-replay/comparison.png
```

For native reruns use the exact build commands and structured command arrays in
`provenance.json` with unique new labels. The native production source in this
working tree (including its preserved PF2–PF4 changes) and the dependency stack
in `build-particle-free/native` are required; this field archive is a mathematical
replay package, not a standalone ASPECT distribution.
