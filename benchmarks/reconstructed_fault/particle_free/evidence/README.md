# Committed evidence summaries

The source commits retain PF5 `assessment.json`/`verification.json`, selected
PF6a/transfer/domain-free/mature-history verification and measured summaries,
the WENO candidate diagnostic summary, and the BP3 startup regression, parameter
invariants and resource costs. Stage-specific README files describe the original
evidence packages. The full measured results and limitations are also in
[the phase reports](../../../../doc/reconstructed_fault/particle_free/STATUS.md).

Detailed run/source manifests, archived fields, binaries, checkpoints, rendered plots,
logs and earlier development evidence remain local. They are intentionally
excluded from the source commit. In the stage README files, archive-replay
instructions and links to excluded data apply when that original local package
is available; they are not a claim that a fresh checkout contains those data.
Historical phase reports retain their original local-evidence references.

The committed summaries record measured errors and gates at their reported
pre-commit working trees. PF5 records its second-order prescribed update;
later summaries retain failed native quadrature/spatial/endpoint-temporal screens
and `strict_reference_match_passed=false`. BP3 startup records the rank-1-only
wall-stop control and exact restart matches on the small fixture; the full-grid
startup remains prepared and unexecuted. Artifact hashes, absolute paths and
revision identifiers describe those historical experiments. They are not
refreshed by a later commit or a claim about untested changes. Related JSON
filenames and raw replay paths can refer to the original local package.

For fresh verification, build the observer sources and use the bounded runner
and independent assessments in the [benchmark README](../README.md). No build,
transport campaign, threshold tuning or coupled experiment runs automatically.
