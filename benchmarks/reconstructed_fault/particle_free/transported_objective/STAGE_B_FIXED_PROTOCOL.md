# Stage B first-part protocol — 2 November 2026

This protocol precedes numerical execution. Scope is a fixed, infinite straight
oblique mature fault viewed in a finite Cartesian observation square, fixed
normal profile, no advection, constant matched G/eta. This isolates the spatial
reaction/history-representation blocker. Moving profiles, heterogeneous eta,
coupled native mechanics, RSF/growth, transfer and production admission remain
later work. No production checkpoint or executable is used.

## Equations and reference

In global xx,yy,xy components, with implicit zz=−xx−yy:

    tau_dot = [W,tau]−r tau+2G(D−chi V(t)S)
    T_dot   = [W,T]−r T+2G D
    s_dot   = V(t)−r s
    R_dot   = [W,R]−r R+[W,2G chi s S]
    tau_sep = T−2G chi s S−R.

The source sign/factor follows direct substitution, not an assumed numerical
cancellation. Initial T=tau0, s=0, R=0. Compare evolved R with an independently
coded direct component ODE; do not define R from the direct answer. Use a closed
complex-component direct solution (mean/anisotropy/shear) as an independent
pointwise reference; check it once against a separate component RK4 integration.
For constant-in-time W the projected Q2 reaction operator is diagonalized and
its forcing integrated analytically: spatial studies have no time-step error.

Choose t=(cos37°,sin37°), n=(-sin37°,cos37°), z=n·x,
S=sym(t⊗n), chi=exp(-(z/ell)^2)/(ell sqrt(pi)), ell=.06m.
The full-line profile integral is1 exactly; no finite-domain renormalization,
normalization floor, artificial tip or fault completion is introduced.
Observation square [-.36,.36]^2 m. A compatible local velocity-gradient field
is generated by v=t U(z)+a(t·x)t−a z n, with U'(z)=k(z),
k=.55+.35 tanh(z/ell), a=.04/s:

    D=k S+a(t⊗t−n⊗n), W=k(t⊗n−n⊗t)/2.

This velocity only defines imposed gradient/spin data in the no-advection
reaction control; it is not a solved stationary material trajectory.
G=3e6Pa, eta=1.5e7Pa s, r=.2/s, duration1.7s,
V(t)=.03[1+.25 sin(1.3 t)]m/s.
Initial xx=.07G, yy=.03G, xy=.04G, zz=−.10G.
The model is a synthetic hypoelastic algorithm test, not an Earth-scale
