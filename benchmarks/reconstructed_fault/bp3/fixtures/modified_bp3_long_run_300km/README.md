# 300-km modified-BP3 long-run fixture

Generated by `prepare_300km_fixture.py` from the maintained ordinary 200-km
fixture. Box: [-100,200] x [0,100] km, centered at (50,50) km. Current dip:
60 degrees; ell=400 m. No 30-degree input is implied by the larger box.

There are 36,282 active squares, with sides 97.65625–12500 m. The generator
splits the eight prior 25-km squares and adds two exterior 50-km strips as
12.5-km squares. Coarse cells are renumbered for the 6x2 Box root grid; actual
exported IDs and coordinates were checked. All other original physical cells
are retained, including all fault-crossed and endpoint cells. The fault,
prestress and paired completion files are byte-identical to the ordinary
200-km inputs, with hashes in `manifest.json`.

The main PRM selects this leaf tree directly; environment mesh selectors are
not required. Fault-region grid spacing is unchanged. This is a domain-width
and far-field-grid change, not evidence of earthquake-cycle or 30-degree
accuracy. See `long-run-cleanup/clean-300km/mesh_output_verification.json` for
the actual-mesh and native quadratic-output checks.
