# Clean-start stress transfer/update test

## Outcome

The production history cycle generates and retains a subcell shear-stress mode
starting from **zero** particle/FE stress. The first mechanical update is weakly
equilibrated, but its subsequent particle-to-FE transfer is not moment preserving.
The next solve therefore receives a new weak load. Subcell particle stress then
accumulates approximately linearly over the four updates.

This demonstrates a mechanism, not the complete origin or magnitude of the
MPa normal-stress bands in BP5. The small horizontal, prescribed-slip test has
essentially zero normal stress initially and does not exercise an inclined free
RSF fault. No production correction is proposed as already qualified.

## Controlled problem and scope

- Box 0.25 x 1 m, y in [-0.5,0.5], periodic x; 16 x 64 square bulk cells,
  h=0.015625 m; Q2 bulk velocity and stress-history fields, Q1 phase/fault fields.
- Horizontal fault at y=0, structural spacing 0.03125 m; ell=0.15625 m
  (ell/h=10), stationary distance profile with core phi=0.6, prescribed directly
  at phase DoFs on every step. Full production normalization/localization.
- Mature C=0, frozen phase/H, native bulk work measure. No endpoint continuation
  is needed for this horizontal periodic bulk configuration; surface endpoints
  remain independent. All surface rates are prescribed, so the surface residual
  criterion is trivially satisfied and is not evidence of free-RSF qualification.
- Zero initial Maxwell stress, G=1e6 Pa, eta=1e20 Pa s; beta rounds to one.
  Uniform top/bottom loading u_x=0.01 y m/s and u_y=0. Prescribed fault
  V=0.005 m/s, not an imposed bulk velocity solution.
- Artificial initialization interval 0.1 s, with supplied zero stress retained.
  Four real dt=0.1 s steps, ending at 0.4 s. Ordinary accepted stress/state
  updates; fixed particle positions isolate transfer/update from advection.
- 3 x 3 particles per cell, production distance-weighted interpolation,
  incident-cell ADD/count averaging, physical constraints and Maxwell commit.
  There is no new constitutive or transfer implementation in the plugin.

The first free-RSF version of the tiny fixture failed during initialization,
before usable history evidence. It is preserved under `failed-free-RSF/`.
The diagnostic was then deliberately restricted to a prescribed uniform source
to isolate the requested bulk history cycle, not to qualify RSF startup.

## Results

One-rank Release main run: **9.20 s**, peak child RSS **290296 KiB (283.5 MiB)**,
initialization plus four accepted steps. All printed fresh linear checks passed.
Final relative bulk residuals at initialization and steps 1–4 were respectively
7.736e-10, 2.682e-10, 5.191e-10, 4.572e-10, 4.828e-10 (target 1e-8).
No nonlinear tolerances or budgets were changed. There were 9216 parents.

| After real step | Within-cell particle tau_xy RMS about each cell mean (Pa) | Incoming particle minus constrained-FE tau_xy at identical parent positions (Pa RMS) |
|---|---:|---:|
| 1 | 1.54453 | 0 |
| 2 | 3.08905 | 1.40985 |
| 3 | 4.63393 | 2.82451 |
| 4 | 6.17999 | 4.24287 |

The second column removes the growing physical cell mean. The third uses the
preceding committed particle history and that step's actual working FE history.
It is not a comparison of different sample positions or physical times.
Particle updates reproduce the production Maxwell formula to 2.28e-13 Pa;
each next incoming tensor equals the preceding committed tensor exactly.
Particle positions, phase, chi and prescribed V remain identical throughout.
The mean shear also grows by about 500 Pa per step under the imposed loading:
the within-cell variation remains approximately 0.309% of that mean. Four
steps show accumulated forced discretization structure, not exponential
instability or an increasing relative error.

### First generation: weakly invisible subcell mode

At step 1 the cell-mean mechanical shear is uniform:
500.000762686446–500.000762686456 Pa. Yet one representative cell
`2_4:1123` has these actual Gauss-point shear stresses:

| Normal coordinate y (m) | Current mechanical tau_xy (Pa) |
|---|---:|
| 0.048635963522 | 494.1645261204 |
| 0.054687500000 | 507.2960583940 |
| 0.060739036478 | 494.1645261204 |

Tangential Gauss points agree. Relative to the cell mean, the deviations are
approximately (-5.83624, +7.29530, -5.83624) Pa: the 5:8:5 Gauss weights cancel
their constant moment, and symmetry cancels their linear moment. Across all
cells, the maximum centered first moment, normalized by h, is 2.43e-12 Pa.
The first-step current-stress weak load on unconstrained velocity tests has
l2 norm 6.94e-12 (Pa m, per unit out-of-plane thickness).

Thus the first subcell mode is generated by the **discrete strain/localized
source compatibility**, even with zero history. A Q2 velocity has a linear
normal shear-strain profile within each cell in this homogeneous setting;
the nonlinear localization evaluated from Q1 phi is not linear. Mechanics
equilibrates the resolved weak moments, not every pointwise stress value.

### Transfer makes part of the mode mechanically visible

Freeze the accepted velocity/source at step k. Compare its current constitutive
tensor at native bulk QPs with the history actually reconstructed for step k+1.
Using the same Q2 velocity test functions, 3 x 3 Gauss rule, periodic x
identification, and removal of prescribed top/bottom velocity rows gives:

| Transfer after step | Shear tensor difference at QPs (Pa RMS) | Weak-load difference l2 (Pa m) |
|---|---:|---:|
| 1 | 2.08034 | 0.0672939 |
| 2 | 2.08854 | 0.116882 |
| 3 | 2.09424 | 0.168486 |

These are representation jumps at fixed accepted fields, **not** nonlinear
residuals of the following converged solve. The independent integration was
checked against the plugin's production-FEValues local history-load norms:
maximum discrepancy 3.42e-12. A separate constant-tensor test confirms zero
free weak load after periodic identification and physical velocity constraints.

For the stored parent tensor P and its constrained FE reconstruction L(P),
the two stress evaluations at the same parent position satisfy, in this test,

    particle commit:    P_new = beta P_old + increment
    mechanical stress:  T_new = beta L(P_old) + increment

Their difference is beta (P_old - L(P_old)). Retaining the parent history
preserves subcell content which mechanics does not see in the same form.
The subsequent DWA/Q2 reconstruction also does not preserve the equilibrated
weak moments. Together these provide a concrete generation/retention/forcing
cycle. They do not by themselves establish a bug in component indexing or
history timing, or prove the eventual BP5 normal-stress amplitude.

Published versus constrained working FE tensors differ by at most 0.01619 Pa
by step 4, unlike the nonperiodic deep BP5 extracts where that difference was
zero. The analysis retains the actual constrained working tensor throughout;
it never silently substitutes the published field. The small normal components
generated later are not used as a claim to reproduce the BP5 normal bands.

## Near-zero-source control and limitations

One extra control used V=1e-12 with everything else unchanged. Initialization
converged, but real step 1 stopped at the unchanged pressure-compatibility guard:
component 2.68779e-15 versus allowed 2.98602e-20. The failed control is retained
under `near-zero-control/`, runtime 5.85 s. It is **not** a passing zero-source
history-cycle comparison. No pressure or stopping-rule correction, tolerance
change, or retry was performed. The successful finite-source experiment and
its exact first-update moment checks stand independently of this control.

No MPI scaling or two-rank replay was performed for this new fixture. Previously
qualified constant/affine transfer checks are reused, not claimed as a new MPI
qualification. The result supports a next **benchmark-only moment-consistency
comparison** on this same small test before choosing a production transfer or
stress-storage change. A rotated fault/BP5 extrapolation remains unqualified.

## Files and reproduction

No ASPECT production source changed. Added benchmark files are
`../clean_stress_cycle.cc`, `../clean_stress_cycle.prm`,
`../clean_stress_control.prm`, `../run_clean_stress_cycle.py`,
`../analyze_clean_stress_cycle.py`, and `../test_clean_stress_cycle.py`.
`../CMakeLists.txt` adds only the opt-in plugin target.

Build/run from the repository root (requires the existing trace hooks):

```sh
cmake -S benchmarks/reconstructed_fault/bp5 -B benchmarks/reconstructed_fault/bp5/build -DAspect_DIR="$PWD/build-pf-cpdi"
cmake --build benchmarks/reconstructed_fault/bp5/build --target bp5_clean_stress_cycle -j4
python3 benchmarks/reconstructed_fault/bp5/run_clean_stress_cycle.py --binary build-pf-cpdi/aspect-release
```

The runner sets the diagnostic environment, imposes a 120-s hard cap, and
refuses to overwrite evidence. It does not launch the nonpassing control
automatically. For a server, use the same source and prm with a compatible
ASPECT build; no large checkpoint or BP5 loading prefix is required.

Saved accepted output is `main/output-clean-cycle/`, log
`main/clean-cycle-run.log`, and execution metadata `main/clean-cycle-execution.json`.
`clean_cycle_analysis.json` inside the accepted output contains the numerical
tables, component statistics and representative native QPs. Reproduce analysis:

```sh
python3 benchmarks/reconstructed_fault/bp5/analyze_clean_stress_cycle.py benchmarks/reconstructed_fault/bp5/clean-stress-cycle/main/output-clean-cycle
python3 benchmarks/reconstructed_fault/bp5/test_clean_stress_cycle.py
python3 benchmarks/reconstructed_fault/bp5/test_stress_cycle_analysis.py
```

The new weak-load unit test and the two existing offline Q2/measure tests pass.
The plugin was built with -j4. The ASPECT binary hash is recorded in the execution
metadata; its reported revision is 33228369d, with the pre-existing working-tree
changes untouched. The main run used a fixed 0.005 plugin constant; the later
control exposed that same default as an explicitly selected diagnostic parameter.
This parameterization does not alter the default calculation; the control's
post-initialization failure is not hidden as verified behavior.
