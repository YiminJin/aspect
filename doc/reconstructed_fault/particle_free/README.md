# Selected particle-free evidence

| Study | Preserved finding and evidence |
|---|---|
| Mature transport, stress rotation and phase basis | The [bulk-spin comparison](BULK_SPIN_CORRECTION_REPORT.md) and [Bernstein report](NATIVE_DG_BERNSTEIN_REPORT.md) document the small controls. The [four-run closeout](MATURE_FAULT_TEMPORARY_CLOSEOUT.md) records the coupled errors, both signs of drift, timestep and mesh comparisons. All four rotating restart sets and the local overnight reductions described in the [validation report](DGQ2_COUPLED_VALIDATION_REPORT.md) remain available. |
| Historical full-section propagation | [Reference sections](TIP_REFERENCE_SECTIONS_REPORT.md) identifies the earlier 80/40 μs comparison, its solver and its material frame. The final intervals and their restart parents survive. |
| Localized propagation and strip width | [Direction and strip resolution](TIP_DIRECTION_AND_STRIP_RESOLUTION.md) documents the work adjoint, angular criterion and width dependence. The [fixtures and reducers](../../../benchmarks/reconstructed_fault/particle_free/reference_sections/README.md) have separate inputs for these controls. |
| Midpoint | The [scientific reference](MIDPOINT_UPDATE_CLOSEOUT.md) freezes the passing mature and oblique controls. The [phase and work audit](MIDPOINT_PHASE_AND_WORK_AUDIT.md) explains the timestep-sensitive 5–10 ms trajectory. Its propagation timing remains unqualified. |
| BP3 and server evidence | The [BP3 review](BP3_REVIEW.md) identifies the production first event. Raw start and resumed server results remain with the [first-event fixture](../../../benchmarks/reconstructed_fault/particle_free/bp3_dg_first_event/). The later surface-cohesive episode has its [own server package](../../../benchmarks/reconstructed_fault/particle_free/rsf_episode_server/). |

Use the [recovery and retirement record](../WORKTREE_CLEANUP.md) to determine which raw data exist locally. The pre-cleanup tag identifies historical tracked files at their original paths.
