2. IMPLEMENT A SUBSTANTIVE, SMALL SOLVER IMPROVEMENT

Use the measured cause to select the simplest effective modification. The
preferred first candidate is a coupled block preconditioner, with a justified
inexact-Newton tolerance policy if oversolving is significant. Implement and
compare candidates one change at a time so their effects remain interpretable.

Write the constrained free-unknown tangent as

             [ J_mm   J_mb ]
       J  =  [             ],   m=(displacement increment, pressure),
             [ J_bm   J_bb ]     b=free Bernstein phase coefficients.

Every block includes the appropriate condensed section derivative. The exact
outer action remains BulkTipCoupling::vmult(), including section integration,
its work adjoint, pressure constraints and active-bound treatment.

Use ASPECT's existing Stokes inverse as an approximate mechanical inverse, not
as a replacement physical Jacobian. A block triangular application or a practical
approximation of J_bb - J_bm J_mm^{-1} J_mb can include coupling absent from the
current preconditioner. Derive signs, row/variable scalings and free/active
restrictions explicitly. This is guidance, not a requirement to construct an
exact Schur inverse or assume J_mm is invertible in every admitted limit.

If useful, expose block actions through the existing coupling operator, retaining
its distributed section reductions. Avoid duplicate constitutive derivatives,
global dense phase/section matrices, and a replicated full-system direct solve.
Retain FGMRES when inner actions are variable/inexact. Keep any positive phase
approximation clearly separate from the possibly nonconvex physical tangent.
Charge every additional Stokes application to the measured cost.

If excessive linear accuracy dominates, use a residual-based inexact-Newton
forcing policy that tightens toward convergence. Derive it in the actual scaled
mechanics/phase norms, and account for linearized bound/KKT checks. Do not merely
replace a small hardcoded tolerance by a looser constant. An approximate direction
must still pass true residual, feasibility and globalization checks. Preserve
the admissible incompressibility needed by the functional line search; an
inaccurate continuity solve cannot be justified by a cheap direction alone.

If repeated search failures dominate instead, improve the existing constrained
search using the measured failure. Reusing a previous active classification as
an initial guess is permissible only if both lower and upper coordinates can
still be released. Reusing a successful search metric is permissible only with
fresh physical evaluation and acceptance. Do not freeze an active set, introduce
a damage cap, or add physical damping to suppress the difficulty.

Keep the final mechanics 1e-9, phase KKT 1e-7, dissipation and scaled 1e-10
independent ledger gates. Preserve the point law, BE endpoint/age convention,
quadrature, obstacle, prescribed compression, material/loading parameters and
accepted-parent semantics in the numerical comparisons. No post-clipping.

A useful engineering aim is at least a factor-of-two reduction in expensive
step wall time. This is a target, not permission to weaken equations or gates.
Retain an improvement only on measured cost/correctness evidence. If an honest
improvement is smaller, explain the remaining cost rather than tuning the test
or multiplying speculative solver variants.

temporal-convergence study. It cannot remove time error already in the parent.
Algebraic ledger closure is not physical-work accuracy. Do not subtract the BE
