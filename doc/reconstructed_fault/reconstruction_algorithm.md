# Reconstruction algorithm — direct Q1 phase-field weighted ridge fit

## Authority and scope

This file is the mathematical authority for the 2-D operation

\[
\mathcal R:
\left(\phi_h,\Gamma_{\rm ref}\right)
\longrightarrow
\Gamma_{\rm fit}.
\]

It replaces the reconstruction mathematics in `specification.tex`.

`stage4.md` describes how this operator is implemented and integrated into ASPECT. It should not redefine the mathematics in this file.

The method is inspired by Xu et al.'s ridge-regression reconstruction, but is adapted to the present problem in two important ways:

1. the solved \(Q_1\) phase field is used directly as a continuous spatial weight;
2. the regression is performed in curvilinear coordinates attached to a reference fault, rather than requiring the fault to be a graph in a fixed global Cartesian direction.

The current implementation is 2-D only.

---

## 1. Reference fault and representation of the fitted fault

Let the ordered reference fault be

\[
\Gamma_{\rm ref}:
\boldsymbol X_{\rm ref}(s),
\qquad
0\le s\le L,
\]

where \(s\) is arc length.

At initialization,

\[
\Gamma_{\rm ref}=\Gamma_{\rm prescribed},
\]

the user-specified pre-existing fault from Stage 3.

Later, the same reconstruction kernel may use an existing sharp fault or a temporary candidate extension as the reference geometry. The later propagation/commit logic is outside Stage 4.

Let

\[
\boldsymbol t_{\rm ref}(s)
\]

be the unit tangent and choose a consistently oriented unit normal

\[
\boldsymbol n_{\rm ref}(s).
\]

The reconstructed fault is represented by a scalar normal-offset field:

\[
\boxed{
\boldsymbol X_{\Gamma}(s)
=
\boldsymbol X_{\rm ref}(s)
+
\delta_h(s)\boldsymbol n_{\rm ref}(s)
}.
\]

This is a deliberate modeling assumption: the fitted fault must remain inside a valid tubular neighborhood of the reference fault so that it can be represented as a single-valued normal displacement.

This formulation is attractive because it is independent of the global orientation of the fault: horizontal, inclined, vertical, and moderately curved faults are handled in the same \((s,\eta)\) coordinates.

---

## 2. Structural discretization

Resample the reference fault at approximately uniform arc-length spacing \(h_\Gamma\).

Let

\[
N_{\rm seg}
=
\max\left(
1,
\left\lceil \frac{L}{h_\Gamma}\right\rceil
\right),
\]

\[
\Delta s_\Gamma=\frac{L}{N_{\rm seg}},
\qquad
p=N_{\rm seg}+1,
\]

and

\[
s_j=j\Delta s_\Gamma,
\qquad
j=0,\ldots,p-1.
\]

Define

\[
\boldsymbol R_j
=
\boldsymbol X_{\rm ref}(s_j).
\]

Represent the unknown offset by one-dimensional linear shape functions:

\[
\boxed{
\delta_h(s)
=
\sum_{a=0}^{p-1}
N_a^\Gamma(s)\beta_a
}.
\]

The unknown vector is

\[
\boldsymbol\beta
=
(\beta_0,\ldots,\beta_{p-1})^T.
\]

For a given \(s\), at most two \(N_a^\Gamma(s)\) are nonzero.

---

## 3. Curvilinear coordinates of a bulk point

For a bulk point \(\boldsymbol x\) near the reference fault, find the closest point

\[
\boldsymbol x^\ast
=
\boldsymbol X_{\rm ref}(s(\boldsymbol x)).
\]

For the current piecewise-linear reference fault, closest-point evaluation can be performed segment by segment by projecting onto each segment and clamping the local segment coordinate to \([0,1]\).

Define the signed normal coordinate

\[
\boxed{
\eta(\boldsymbol x)
=
\left(
\boldsymbol x-\boldsymbol x^\ast
\right)
\cdot
\boldsymbol n_{\rm ref}(s(\boldsymbol x)).
}
\]

Thus a diffuse phase-field point near the fault is represented by

\[
(s,\eta).
\]

The regression fits the center of the diffuse band as

\[
\eta=\delta_h(s).
\]

---

## 4. Reconstruction region

For each reference fault define a tubular reconstruction region

\[
\Omega_\Gamma
=
\left\{
\boldsymbol x:
\operatorname{dist}
(\boldsymbol x,\Gamma_{\rm ref})
\le R_\Gamma
\right\}.
\]

Only the part of the bulk domain in \(\Omega_\Gamma\) contributes to this fault.

At initialization, choose \(R_\Gamma\) large enough to contain the stationary diffuse profile generated by Stage 3, with a small discretization margin. Reuse existing `PhaseField::PhaseFieldProfile` information where practical rather than duplicating the stationary-profile formula.

Different faults must not contribute ambiguously to the same active region.

The exact spatial-search acceleration is an implementation detail.

---

## 5. Phase-field weight

Let

\[
\phi_h(\boldsymbol x)
\]

be the converged solved \(Q_1\) phase field and let

\[
\phi_{\min}
\]

be the lower acceptable phase-field bound obtained from the existing phase-field/material-model interface.

Use

\[
\boxed{
\omega(\phi)
=
\max(\phi-\phi_{\min},0)
}.
\]

A normalized equivalent may be used only if its effect on the ridge scaling is handled consistently.

No separate high damage threshold is introduced.

The reconstruction must therefore work for partially mature faults whose core value is substantially below one.

---

## 6. Weighted ridge-regression functional

Use the solved finite-element field directly:

\[
\boxed{
J_{\rm data}(\boldsymbol\beta)
=
\frac12
\int_{\Omega_\Gamma}
\omega(\phi_h(\boldsymbol x))
\left[
\eta(\boldsymbol x)
-
\delta_h(s(\boldsymbol x))
\right]^2
\,d\Omega .
}
\]

Substituting the structural interpolation,

\[
J_{\rm data}
=
\frac12
\int_{\Omega_\Gamma}
\omega(\phi_h)
\left[
\eta
-
\sum_aN_a^\Gamma(s)\beta_a
\right]^2
\,d\Omega.
\]

This is the direct finite-element analogue of Xu's least-squares fitting idea.

No thresholded equal-weight point cloud is constructed and no artificial normal-line phase-field sampling points are generated.

---

## 7. Finite-element assembly

Evaluate the integral with ordinary bulk finite-element quadrature.

For every locally owned bulk cell relevant to \(\Omega_\Gamma\), and for every quadrature point \(\boldsymbol x_q\):

1. evaluate the actual solved \(Q_1\) field
   \[
   \phi_q=\phi_h(\boldsymbol x_q);
   \]

2. calculate
   \[
   w_q=\omega(\phi_q);
   \]

3. skip the point if \(w_q=0\);

4. find its closest point on \(\Gamma_{\rm ref}\);

5. calculate
   \[
   s_q=s(\boldsymbol x_q),
   \qquad
   \eta_q=\eta(\boldsymbol x_q);
   \]

6. evaluate the structural shape functions \(N_a^\Gamma(s_q)\);

7. assemble

\[
\boxed{
H_{ab}
\mathrel{+}=
JxW_q\,
w_q\,
N_a^\Gamma(s_q)
N_b^\Gamma(s_q)
}
\]

and

\[
\boxed{
g_a
\mathrel{+}=
JxW_q\,
w_q\,
N_a^\Gamma(s_q)
\eta_q .
}
\]

Equivalently,

\[
H_{ab}
=
\int_{\Omega_\Gamma}
\omega(\phi_h)
N_a^\Gamma N_b^\Gamma
\,d\Omega,
\]

\[
g_a
=
\int_{\Omega_\Gamma}
\omega(\phi_h)
N_a^\Gamma\eta
\,d\Omega.
\]

The quadrature points are only the numerical integration points of the FE formulation; they are not a separately generated reconstruction point cloud.

Because the structural basis is linear, every quadrature point contributes to at most two adjacent structural vertices.

---

## 8. Xu-inspired smoothness regularization

Add a second-difference ridge penalty:

\[
\boxed{
J(\boldsymbol\beta)
=
J_{\rm data}(\boldsymbol\beta)
+
\frac12\lambda_s
\|D\boldsymbol\beta\|^2 .
}
\]

For uniformly spaced structural points,

\[
\boxed{
(D\boldsymbol\beta)_j
=
\beta_{j-1}
-
2\beta_j
+
\beta_{j+1},
\qquad
j=1,\ldots,p-2.
}
\]

The resulting reduced system is

\[
\boxed{
\left(
H+\lambda_sD^TD
\right)
\boldsymbol\beta
=
\boldsymbol g .
}
\]

The ridge term is part of the reconstruction algorithm. Do not add a second, independent post-reconstruction smoothing step in Stage 4.

### Scaling of the ridge term

The data term contains the physical measure \(d\Omega\), so the numerical scale of \(H\) depends on the active diffuse-band measure and on the physical units.

The scaling of \(\lambda_s\) must therefore be explicit.

A useful optional normalization is

\[
W_\Gamma
=
\int_{\Omega_\Gamma}
\omega(\phi_h)\,d\Omega,
\]

\[
\widehat H=\frac{H}{W_\Gamma},
\qquad
\widehat{\boldsymbol g}
=
\frac{\boldsymbol g}{W_\Gamma},
\]

followed by

\[
\left(
\widehat H+\lambda_sD^TD
\right)\boldsymbol\beta
=
\widehat{\boldsymbol g}.
\]

Whether this normalization is used should be decided deliberately and tested. Do not hide the choice inside unrelated parameters.

---

## 9. Reconstructed geometry

After solving for \(\boldsymbol\beta\), construct

\[
\boxed{
\boldsymbol X_j
=
\boldsymbol R_j
+
\beta_j\boldsymbol n_j,
\qquad
j=0,\ldots,p-1.
}
\]

The ordered points

\[
\{
\boldsymbol X_0,\ldots,\boldsymbol X_{p-1}
\}
\]

form the fitted sharp fault.

At initialization, these points may be committed as the initial `ReconstructedFault`.

At later timesteps, the generic reconstruction kernel should return temporary fitted geometry; a separate propagation algorithm decides which candidate points are accepted and appended. Previously committed geometry must not be moved merely because the kernel is reusable.

---

## 10. Diagnostics and validity

Accumulate at least

\[
W_\Gamma
=
\int_{\Omega_\Gamma}
\omega(\phi_h)\,d\Omega
\]

and structural support

\[
\boxed{
c_a
=
\int_{\Omega_\Gamma}
\omega(\phi_h)
N_a^\Gamma(s)\,d\Omega .
}
\]

Detect at minimum:

- zero or negligible total phase-field weight;
- structural vertices with no phase-field support;
- non-finite matrix/vector entries;
- failure or singularity of the reduced solve;
- degenerate reference segments/tangents;
- ambiguous overlap between faults;
- fitted offsets large enough that the assumed tubular coordinates are no longer credible.

Do not introduce aggressive empirical thresholds before numerical tests justify them.

These are reconstruction diagnostics, not persistent material-model state.

---

## 11. MPI formulation

The bulk FE problem is distributed; the sharp fault is small and replicated.

Each rank assembles from locally owned cells only:

\[
H_r,\qquad
\boldsymbol g_r,\qquad
W_{\Gamma,r},\qquad
\boldsymbol c_r.
\]

Reduce the small fault-sized quantities:

\[
H=\sum_rH_r,
\qquad
\boldsymbol g=\sum_r\boldsymbol g_r,
\]

\[
W_\Gamma=\sum_rW_{\Gamma,r},
\qquad
\boldsymbol c=\sum_r\boldsymbol c_r.
\]

Apply any global normalization and add the ridge term only after the global data quantities have been formed.

The final small system may be solved identically on every MPI rank.

Do not gather bulk cells, quadrature points, or the full phase-field solution to one rank.

---

## 12. Generic reconstruction kernel

The mathematical operator is generic:

\[
\boxed{
\mathcal R:
(\phi_h,\Gamma_{\rm ref})
\mapsto
(\Gamma_{\rm fit},\text{diagnostics}).
}
\]

It must not contain initialization-only conditions such as `time == 0`.

For Stage 4, only its first use is integrated:

\[
\Gamma_{\rm prescribed}
\overset{\phi_h^0}{\longrightarrow}
\Gamma_{\rm fit}^0
\longrightarrow
\text{initial `ReconstructedFault`}.
\]

Later timestep/candidate construction, crack propagation, acceptance, and append/commit logic are separate tasks.

---

## 13. Deliberate limitation

The method assumes the fitted fault can be represented as a normal graph over \(\Gamma_{\rm ref}\), i.e. that the reference curve defines a valid tubular coordinate system over the reconstruction region.

This is expected to be reasonable for initialization because Stage 3 constructs the diffuse phase field from the prescribed fault itself.

For later propagation, robustness depends on constructing a sufficiently good temporary reference/candidate extension.

If this limitation proves problematic in propagation tests, a less reference-constrained reconstruction method such as the original Xu graph fit can be reconsidered then. Do not silently mix the two formulations in one implementation.

---

## 14. Core verification cases

The implementation should verify at least:

1. **straight symmetric band:** fitted offsets are approximately zero;
2. **known normal shift:** fitted offsets recover a prescribed normal displacement;
3. **partially mature fault:** reconstruction remains correct for a core phase field well below one;
4. **curved reference fault:** a diffuse band centered on a gently curved reference gives near-zero offsets;
5. **AMR invariance:** local mesh refinement does not bias the center merely by adding more nodes, because the FE integral uses `JxW`;
6. **MPI invariance:** different decompositions give the same reduced system and fitted curve;
7. **ridge sensitivity:** increasing the ridge coefficient suppresses oscillatory offsets as expected.
