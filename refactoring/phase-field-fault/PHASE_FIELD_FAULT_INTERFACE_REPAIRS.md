```text
subsection Adiabatic conditions model
  set Model name = function
  subsection Function
    set Variable names      = depth
    set Function constants  = p0=200, dp_dz=50
    # Temperature (K), pressure (Pa), density (kg/m^3). Depth is in metres.
    set Function expression = 293; p0 + dp_dz*depth; 1

end
```

### Locate the pressure on the fault

**Mature trace.** `FaultStokesCoupling::sample_bulk()` already has the first vertex and the segment coordinate of the fault projection. Evaluate the prescribed pressure at that physical point on the current trace. Many bulk quadrature points at different depths can project onto the same point on a dipping fault. They must see the same prescribed fault pressure there. A moving trace must sample its updated physical depth using the geometry for the attempt. Keep the bulk quadrature, transfer weights and resolved-traction path intact.

**Growing fault.** The solver uses one signed rate and one resistance per material strip. Choose and document one physical location per strip for sampling the prescribed profile. Prefer the midpoint of the portion of the represented fault in the strip, using the seed or accepted front geometry and the existing continuation used to locate prospective planes. Define how a newly eligible strip obtains its point and how cut end strips are handled. Freeze these locations from the accepted geometry for the attempt if that is the discretization used. An oblique strip extends across a two-dimensional part of the box. Its bulk centroid, its tangent coordinate treated as depth, and one seed-tip pressure for all strips can all give the wrong value. Do not introduce a new reconstruction algorithm to manufacture a pressure for an unsupported geometry. If some prospective or inactive strips lack a physically defined location, trace whether the solver actually needs their resistance; report the exact qualification and handle that case explicitly.

Use the same section pressure in the signed solve, prospective-plane scoring, the resistance returned to the bulk and frictional work. Enforce the rate law's admissible duration for **every section where it is evaluated**. The current RSF bound is `damping >= N*h*b/Dc`, where `h` is half the attempted duration. The largest relevant compression controls this bound for spatially uniform RSF parameters. Rebuild attempt-local data correctly on retry. A prescribed pressure can vary with position while having zero derivative with respect to the pressure unknown. Preserve the existing rate and phase tangents under that distinction.

Keep the positive-compression domain of the qualified friction law. Report the physical location and value of an inadmissible pressure. A hydrostatic profile can reach zero at the surface, so apply the check where the law actually consumes the pressure. Clipping, taking an absolute value or inserting a hidden pressure floor changes the model. A bad fixed profile needs an input diagnostic rather than repeated timestep cuts.
