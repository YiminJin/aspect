## Baselines and intended examples

The target is release `v3.1.0`, peeled commit `0d97d2d3311154ca3f01d801b18f3945dc8b8bad`. Keep that base fixed during the transplant. Reconciliation with upstream development belongs to a later submission. The scientific reference is the portable archive named in [VERIFICATION.md](VERIFICATION.md). Its mature and tip cases have different source/runtime identities. The sibling worktree provides the research history and working files. Its present HEAD alone cannot reproduce the two cases.

The paper has three examples. The target cases below govern feature selection. The closeout controls in [VERIFICATION.md](VERIFICATION.md) govern numerical equivalence during the port. A publication case enters the evidence record when its own inputs, comparison and results exist.

### Example 1 · Compare the dips first, then change rheology at 60°

Use the existing 60° case to establish the benchmark conventions, then run 30° and 90° with the same chosen slip sense. The SEAS BP3-QD specification includes all three angles and provides normal- and thrust-faulting conventions. Specify which convention the donor implements. Parameterize the friction transition, deep creep boundary and on-fault stations by **down-dip distance**. For example, the 15 km friction transition begins at only 7.5 km vertical depth for a 30° planar fault. At 90° use a tangent/normal or arclength representation valid for a vertical fault. Check the free-surface intersection, effective normal traction and boundary truncation at each dip. Compare slip, slip rate, shear and normal traction against the matching reference curves. Reference-law differences, finite-domain effects and phase regularization belong in the caption or methods. [SEAS BP3 specification, §§1–4](https://strike.scec.org/cvws/seas/download/SEAS_BP3.pdf)

The published 50 MPa is **initial** effective normal compression. BP3 adds the slip-induced normal-traction increment in the strength law. In the donor trace the value actually consumed by RSF as well as the reported traction. A case with a prescribed constant strength pressure can still serve as a BP3-type comparison if that difference is declared. Preserve its existing behavior during migration. [SEAS BP3 specification, Eqs. 13–18](https://strike.scec.org/cvws/seas/download/SEAS_BP3.pdf)

For the 60° viscoelastic extension, pair an elastic reference with the lower-crust viscosity profile and report the Maxwell time and the observation window. Hold geometry, friction, loading, initial state and effective-pressure treatment fixed across a rheology comparison. If the intended lower crust also uses a different deep friction profile, run the elastic comparator with that same profile or describe the combined change explicitly. Specify whether each layer boundary is given in vertical depth or along-fault distance. Useful paired histories are deep aseismic slip and shear-traction recovery updip. If the optional advection run is included, start from the same 60° viscoelastic case and compare frozen and advected geometry at matching material labels. The existing small moving-fault regression remains part of the port even when the manuscript omits this pair.

### Example 3 · A regional mature megathrust with gravity

The proposed first application uses a prescribed curved interface, growth disabled, and a regional thermal structure prescribed over the simulated fault-cycle window. These are initial scope choices. Select the margin and transect with the author when a compatible geometry, temperature model and density constraint are identified. A useful first result is an along-interface profile of temperature, effective normal traction and slip rate under a specified convergence rate, with at least one paired control addressing a stated physical hypothesis.

1. **Regional inputs.** Record section endpoints, projection, vertical datum, units, resolution, model versions and interpolation onto the ASPECT mesh. Use a cited regional thermal model or observationally constrained reconstruction. Supply an independent regional density model or derive density from documented lithology, temperature and an equation of state with regional constraints. State which inputs are observed, inferred or assumed. An imported in-situ density may already include thermal expansion. Apply each density contribution once. Specify how temperature enters viscosity or density. Slab2 is a candidate geometry source, and published thermal transects are candidate thermal inputs. Assess their coverage and select the density source separately. [USGS Slab2](https://www.usgs.gov/data/slab2-a-comprehensive-subduction-zone-geometry-model) · [Syracuse et al., regional thermal models](https://doi.org/10.1016/j.pepi.2010.02.004)
2. **Stress passed to friction.** Trace the body-force term through the actual fault-enabled Stokes residual with the selected ASPECT density, gravity vector and pressure formulation. Establish the physical pressure datum from boundary tractions or a compatible normalization. For tension-positive total stress and compression-positive frictional strength, the proposed effective compression is $p_N^{\mathrm{eff}}=-\mathbf n\cdot(\boldsymbol\sigma_{\mathrm{tot}}\mathbf n)-p_f$, with $p_f$ the specified pore pressure. Document how total stress is reconstructed, including any reference pressure, and count the reference overburden once. State the pore-pressure assumption independently of density and gravity. If the port only offers prescribed effective pressure, distinguish bulk gravity effects from frictional normal-stress feedback. Adding that feedback, including the pressure dependence of a coupled residual/tangent where applicable, is a scientific extension with its own tests. [ASPECT 3.1 pressure normalization](https://aspect-documentation.readthedocs.io/en/v3.1.0/user/methods/pressure-norm.html)
3. **Two checks before interpretation.** First use a level, motionless, vertically stratified column with a known surface pressure. Compare pressure against the integral of density times gravity over depth and effective traction on a sampling plane against the same solution with the prescribed pore pressure. Exercise the actual fault traction evaluator. Then initialize the regional section with compatible boundary loading, gravity, stress and RSF state. Measure startup force imbalance and slip transients separately from the response of interest. Lateral density contrasts can drive flow. Only the simple column has an imposed hydrostatic rest solution.
4. **Physical comparison.** One useful control keeps gravity, geometry, loading, thermal rheology and pore-pressure prescription fixed and substitutes a depth-only reference density for the regional density. Initialize both states consistently under their own body forces. Compare along-interface total and effective normal traction, shear traction and slip rate over the same window. This comparison isolates the modeled effect of lateral density structure. Where energy is reported, include body-force work or its equivalent gravitational-potential-energy change with a consistent sign and reference state.

Example 3 uses ASPECT's existing temperature, material, gravity, boundary and initialization components wherever they fit. Keep regional data loading and pressure conventions visible at those interfaces. A pinned benchmark pressure, a flat fault, or a particular thermal model should never be implicit in a shared friction kernel. During increments 0–1, record any such assumption encountered on the selected code path. Regional model preparation and new pressure coupling have their own later assignment.

An absent example input or a dormant option in the donor is an inventory finding. Use the two passing controls for the paths they cover. Keep the archive accessible for alternate representations, rejected algorithms and negative evidence. Give every project addition reached by these inputs a disposition. Carry it for an example, keep it as a verification fixture, or leave it in the donor. Examples of the last category to investigate are CPDI scaffolding, exact-line comparison machinery, superseded Cartesian test paths, old orientation hypotheses and the former standalone timestep driver. Account separately for ordinary upstream ASPECT capabilities.

### DG stress transport in 4A

The mature fault can select **Advect physical stress** and prescribe **Exterior parent stress** in xx, yy, xy order. At attempt entry the operator advances the accepted DG coefficients with the accepted velocity on a fixed, conforming, nonperiodic 2-D Cartesian box. The material rotates and relaxes this candidate using the accepted bulk-slip-subtracted spin. Both the section solve and Stokes assembler read the same projected parent. The normal post-accept signal publishes physical stress and label history. Existing stationary inputs use the original cell parent.

ASPECT’s scalar DG assembly produces a timestep matrix and a scalar boundary load. The explicit stress operator uses mapped deal.II cell and face values, local inverse mass and stage-wise ghost exchange. A file-local assembly builds the mass-inverted blocks and CFL rate from accepted velocity. SSPRK advancement owns each substep parent and collectively validates each new stage before a halo exchange or return. The [4A record](STATUS.md#increment-4a--accepted-dg-stress-transport) gives the component weak form, release interface decisions, measured receiving-cell action, partition-face transfer and retry results.
