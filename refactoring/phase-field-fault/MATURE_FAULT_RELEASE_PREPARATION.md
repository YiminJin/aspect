**Assignment for the existing implementation thread on `pf-rsf`.** Implement three shared capabilities through the public `phase field fault` material model: initialize a prescribed curved trace from the ordered vertex file, specify the physical shear sense of a mature fault, and continue a boundary-spanning fault from a checkpoint produced by a fresh run of this branch. Deliver separately reviewable commits and one integrated demonstration. Use the current worktree and its `AGENTS.md`; the inspected remote base was `b54bde5174c12212560e6e7872ed3cb96b76436e`. Record the actual starting commit and preserve any newer local Assignment D repairs.

The first scientific users are the straight, right-dipping 60° BP3 thrust and a prescribed curved megathrust. The small cases below qualify their shared machinery. BP3's spatial friction profile, deep-creep boundary, adaptive timestep and normal-traction comparison belong to the subsequent BP3 assignment. Regional temperature, density, gravity and pore-pressure qualification belong to Increment 7. Keep the production launch and release tag for the author. Use the donor only as read-only evidence. All runs here start from this branch's inputs or from checkpoints those runs write.

## 1. Accept a prescribed curved mature trace

Trace the vertex table from `PhaseFieldFault::parse_parameters` to `MaterialFaultTrace::initialize`, `rebuild_segments`, `project`, the phase-profile integral and the mechanical transfer. The initializer currently uses the line between the first and last vertices for collinearity, ordering and boundary contacts. Downstream code already stores segment tangents, normals and cumulative arclength. Reuse the segment geometry where it has the required meaning.

- With `Fit trace to phase = false`, accept an ordered, simple, open 2-D polyline with unequal segment lengths and a changing dip. Preserve the supplied positions and material IDs, including their associated properties. Establish each boundary contact from its box face and its incident segment. Retain the existing interior and boundary contact rules; handle a corner deterministically or diagnose a genuinely ambiguous contact. Validate finite coordinates, nonzero edges, topology and domain membership. A single endpoint-chord projection is insufficient to establish the order of a curved trace.
- The fitted straight seed is a separate existing operation. Its normal offsets, endpoint search and ordering use one seed frame. Preserve its qualified behavior. If a curved input requests that particular fit, give a specific diagnostic directing the reader to the prescribed-curve setting. A new curved ridge-fitting algorithm is outside this assignment. Geometry belongs to the trace; the independent phase field and its profile remain with their present owners.
- Run an ordinary example from a small external vertex file. Choose a visible bend and a nonuniform but resolved phase band. Independently check the contacts, cumulative segment lengths, projections and local normals on both sides of the bend. Exercise a point where a global chord would select the wrong foot or resolve the wrong shear. At the bend and near a boundary check the existing projection/support convention, the in-domain normal integral, and a nonzero bulk-to-fault/fault-to-bulk action. Document any limitation actually encountered with overlapping normal supports. Preserve the straight fitted and prescribed controls and show that a self-crossing or degenerate input fails clearly.

## 2. Give positive mature slip speed a physical sense

Use the existing tangent **t** along increasing material ID and geometric normal **n** obtained by rotating **t** counterclockwise. Document one user choice for the sense of slip. A defensible convention is that a sense factor ε of +1 gives the existing kinematics and −1 reverses the relative tangential motion. The full slip-rate gradient is then χ V ε **t** ⊗ **n**, where χ has units of inverse length and the mature friction law consumes positive speed V. Equivalent representations are welcome if the default preserves existing results. Explain the motion of the positive-normal side relative to the negative-normal side in the parameter description or guide. Avoid encoding a particular dip angle or the words “BP3 thrust” in the shared mechanics.

- Use one consistent signed frame in the actual Stokes load, the reverse shear-traction projection, the accepted stress update, and the bulk-minus-slip spin used to rotate the parent stress. Trace the corresponding paths for boundary and interior mechanics. Keep the geometric normal used to find points and sample compression consistent. State the convention for background shear, speed, accumulated slip and any signed output. Magnitude-based aging uses positive speed; friction history remains law-owned. Reversing the vertex order reverses both **t** and **n**, leaving their dyad unchanged.
- Extend the real assembly probe in `benchmarks/fixed_fault/transfer_work/` and the BP3 check in `refactoring/phase-field-fault/results/bp3-preparation/check_branch.py`. At the frozen parent and common measure, the existing one-cell right-dipping probe gives about **+0.58901895576274 m** for both normalized actions. Predict and measure the negative value under the opposite sense. Reverse the vertex order with physical properties remapped and repeat. Check that resolved compression is invariant under the sense switch **at fixed bulk stress**. On a curved segment, compare with an independent local-frame contraction; agreement between two routines using the same wrong frame would be insufficient.
- Also run one solved right-dipping case. Show the hanging wall moving up dip relative to the footwall under the thrust loading. Supply the two sampling locations, the positive direction, units, and a signed velocity or displacement difference. Choose conditions that distinguish the slip response from imposed background motion, using a matched control if needed. Preserve the positive-speed law and the old default. A complete signed, reversing RSF law is a different scientific change.

## 3. Restart a boundary-spanning mature fault from its own accepted state

Inspect the parameter guard, early returns in `PhaseFieldFault::save/load`, and the first `update()` after restore. Today the guard blocks a boundary-spanning checkpoint, while the first update can fit the seed and build its profile. Make a resumed calculation rebuild derived geometry and profile data from the **restored accepted trace and FE fields**. Apply initial fitting exactly once on a fresh fitted run. A prescribed run starts with the supplied curve.

- Reuse ASPECT's normal checkpoint lifecycle and the mature interior/law serialization where compatible. Identify the owner of accepted positions and IDs, contacts, support radii, slip, rate, persistent loading, resistance-law state and any restart-relevant mechanical memory. ASPECT already owns the bulk FE histories and clock. Save only the physical state required for the next step and distinguish the prescribed input geometry from the accepted fitted geometry. Preserve current interior and stateless-law readers. Reject a continuation that would reinterpret the saved sense, physical trace, topology or law, with a useful diagnostic. Use physical configuration identity so copying an identical vertex file to another directory remains valid.
- For the prescribed curved case, compare an uninterrupted run to a split run restarted in a fresh directory. Use at least one positive interval after saving and compare the first post-restart endpoint by physical IDs: geometry and contacts, normal integrals, accepted slip, speed and law state, native bulk stress, and a load or work quantity. Use a forced rejection/retry against a clean accepted interval to check single publication. Exercise one and two ranks, including a repartitioned continuation if supported by the ordinary ASPECT setup. State what matched exactly and where numerical tolerances were needed.
- Repeat a short continuation on a **straight seed whose initial fit measurably moves it**. This exposes accidental refitting or restoration of the original seed. Deliberately change the slip sense or displace a vertex without changing the vertex count and show the incompatible continuation is rejected. Retain the existing layered interior restart and a law with no age as compatibility checks.
