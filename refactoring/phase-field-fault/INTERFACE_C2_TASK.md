## 3. Implement the complete C2 public interface

1. **One material name and one active route.** Write two runnable parameter inputs showing `Model name = phase field fault`. For growth, the already resolved `midpoint fault phase` field method selects the coupled solve. For an existing trace, use the explicit physical geometry choice and the normal field method. A fixed trace with transported phase, an advected trace, a boundary-fitted seed and irreversible growth must remain distinguishable. Preserve the legacy `growing fault` name and subsections by mapping to the same implementation, with documented precedence and conflicting-input diagnostics. Keep the older automatic geometry inference for existing files. Independent phase fields must run without fault mechanics.
2. **Make dispatch work through normal ASPECT entry points.** Both current material parsers check top-level object identity. The solver validates and casts to `MidpointMaterial`; material initialization installs route-specific assembly, retry, acceptance and restart callbacks. A facade that constructs two nested ASPECT plugins or satisfies the growing interface in its mature configuration can pass a superficial input test and still be wrong. Resolve the route once before route-dependent initialization, activate only its state and callbacks, preserve one publication per accepted step, validate the active route explicitly and reject incompatible output or checkpoint use cleanly. Keep the separate pressure closures, material outputs, solvers and 2-D growth restriction. Preserve the documented mature boundary-spanning restart limitation. Exercise the existing benchmark material extensions as well as the normal new inputs.
3. **One ordered mature vertex file.** Read once and distribute using the release ASCII reader convention. Use documented stable material IDs and named coordinates in metres. Allow named optional columns `initial_age_s` and `background_shear_Pa`. Order fixes the slip sense. Reject invalid IDs/order, nonfinite values, incompatible geometry, ambiguous duplicate sources and age on a stateless law. Preserve scalar fallbacks and legacy inline lists. Per-label background shear replaces the scalar and persists through timesteps. Historical donor files use their third column for core phase; diagnose an ambiguous format. Old checkpoints remain readable. The saved material identity and evolved width must survive resume and MPI repartition. Show a file-based input beside the equivalent old one.
4. **One place to choose and construct friction.** Both material files currently declare the RSF coefficients and have separate `make_resistance()` functions. The stateless benchmark implements one law but registers two derived material classes. Give the rheology one reader/constructor and one extension point for an actual law, retaining route-specific historical defaults. Use the existing law-owned history. Keep mature positive-speed evaluation at fixed age and the signed, stage-aged growing solve as distinct contracts. A developer adding a second law should implement it and declare its parameters once. Neither fault geometry nor the output plugin should require an RSF downcast to decide whether to store or print age. Preserve old archive keys and supported layouts explicitly at the compatibility boundary.
